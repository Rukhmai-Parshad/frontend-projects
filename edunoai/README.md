# EdunoAI

A responsive educational website built using HTML5 and CSS3 to strengthen frontend development fundamentals through practical implementation of modern web design principles, responsive layouts, and multi-page website development.

This project was developed as a learning project to practice building structured web pages, consistent user interfaces, responsive navigation, and reusable styling techniques.

---

## Features

- Responsive website layout
- Multi-page website architecture
- Home page
- About page
- Courses page
- Blog page
- Individual blog articles
- Contact page
- Responsive navigation menu
- Image-based content sections
- Modern educational website interface

---

## Technologies Used

- HTML5
- CSS3
