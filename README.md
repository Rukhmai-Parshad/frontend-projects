# Frontend Projects

A collection of frontend projects built using HTML, CSS, and JavaScript to strengthen web development fundamentals through responsive layouts, modern UI design, and practical implementation of frontend concepts.

The projects in this repository focus on building practical websites and user interfaces while following clean code organization, responsive design principles, and maintainable project structure.

---

## Projects

| Project | Description | Technologies |
|----------|-------------|--------------|
| **EdunoAI** | A responsive multi-page educational website featuring course pages, blog sections, contact page, and modern UI components built as a frontend learning project. | HTML5, CSS3 |

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Rukhmai-Parshad/frontend-projects.git
```

### Navigate to the Repository

```bash
cd frontend-projects
```

### Open a Project

Navigate to the desired project folder and open the `index.html` file in your preferred web browser.

Example:

```bash
cd edunoai
```

Then open:

```text
index.html
```

Refer to the individual project documentation for project-specific information.
